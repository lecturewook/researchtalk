# 하루 대화 AI 요약 — 선택 연결

현재 앱은 AI 연결을 꺼 두었습니다. 단체·개인 대화와 날짜별 보관·파일 저장은 AI 없이 동작합니다.

AI를 연결할 때만 다음 작업을 합니다.

1. 이 폴더의 `api/summarize.js`를 **app/api/summarize.js**로 복사합니다.
2. Vercel 환경 변수에 **OPENAI_API_KEY**와 **RESEARCHTALK_SUMMARY_PASSCODE**를 넣습니다. 연결 코드는 예측하기 어려운 24자 이상의 새 문자열로 만듭니다.
3. 선택 사항으로 **OPENAI_MODEL**을 지정할 수 있습니다. 기본값은 `gpt-5.4-mini`입니다.
4. `app/config.js`의 `aiEnabled:false`를 `aiEnabled:true`로 바꿉니다.
5. app 폴더에서 **npm run build**를 실행하고 `sw.js`의 캐시 이름을 한 단계 올린 뒤 다시 배포합니다.
6. 사용할 사람이 대화방의 **하루 대화 요약**을 누르고 요약 연결 코드를 입력합니다. 연결 코드는 기기에 저장하지 않습니다.

요약할 때 **현재 선택한 대화방과 하루의 메시지, 표시 이름, 시간**만 OpenAI로 보냅니다. 개인방의 요약은 그 방의 두 사람에게만 저장됩니다. 요약 중 대화가 바뀌면 오래된 결과는 저장하지 않습니다. 대화 삭제 시 해당 날짜의 요약도 지웁니다.

한 번에 대화 400개·24,000자까지 보냅니다. 요청은 `store:false`로 설정했습니다. API 사용료가 발생하며 Vercel 함수 하나를 사용하게 됩니다. 실제 AI 요청은 이번 작업에서 실행하지 않았습니다.

API 키는 Vercel 환경 변수에만 보관하고 `config.js`나 브라우저, 이 대화창에는 넣지 않습니다. 연결 코드는 AI 요청을 허용하는 별도 코드이며 사용량 한도 설정을 대신하지는 않습니다.
